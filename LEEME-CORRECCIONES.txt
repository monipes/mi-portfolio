CORRECCIONES MISS SAM — ACTUALIZACIÓN

Este paquete reemplaza al ZIP anterior. Incluye los mismos archivos e imágenes, con dos ajustes adicionales:
- El botón TikTok de la tienda usa ahora exactamente el mismo fondo de acento que Facebook e Instagram; se eliminó el rojo diferente que lo hacía desparejo.
- Se corrigieron las expresiones regulares del script de publicación programada. En la versión anterior estaban escapadas de más y no detectaban correctamente published, publish_at ni los encabezados YAML. El script actualizado ya pasó la comprobación sintáctica de Node.js.

APLICACIÓN
1. Descomprimí este ZIP.
2. Copiá su contenido dentro de la carpeta raíz del repositorio.
3. Elegí combinar carpetas y reemplazar los archivos existentes.
4. Subí los cambios a la rama main.

PUBLICACIÓN AUTOMÁTICA
El workflow está configurado para ejecutarse cada cinco minutos y procesa fechas en horario de Argentina (UTC-3 cuando el artículo no especifica zona horaria). Cuando alcanza la fecha, vacía publish_at y hace un commit para disparar el despliegue.

IMPORTANTE: esto corrige el código del paquete, pero no permite garantizar la publicación automática hasta que los cambios estén en GitHub y se compruebe una ejecución exitosa en Actions y un despliegue correcto en Cloudflare Pages. GitHub Actions debe estar habilitado y Cloudflare Pages conectado a main. El artículo de inteligencia artificial publicado manualmente no se modifica.

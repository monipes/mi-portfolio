FLECHITA VOLVER ARRIBA:
La plantilla general Base.astro del proyecto original ya contiene el botón global de volver arriba; por eso no se incluye ni reemplaza ese archivo. También funciona en Visión Alternativa.

CÓMO USAR:
Descomprimí este ZIP y copiá su contenido dentro de la carpeta del proyecto original, conservando las rutas. Cuando Windows pregunte si querés combinar carpetas y reemplazar archivos, aceptá reemplazar únicamente los archivos con el mismo nombre. No borres el resto del proyecto.

IMPORTANTE SOBRE LA PROGRAMACIÓN:
El workflow se ejecuta los martes a las 23:00 UTC (20:00 Argentina) y genera un commit para activar el despliegue conectado a GitHub en Cloudflare Pages. Para que funcione, GitHub Actions debe estar habilitado y Cloudflare Pages debe estar conectado a la rama main. La primera publicación depende de que el primer despliegue con estos cambios termine correctamente.

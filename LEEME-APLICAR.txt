MISS SAM — GOOGLE ANALYTICS 4 (GA4)

ID de medición incorporado: G-5PKYXG6CRR
ID del flujo web: 16406229059 (referencia de Analytics; no se necesita en el código de instalación)
ID de contenedor de Google Tag Manager recibido: GTM-TJ9835KL (no se utiliza en esta integración directa de GA4)

QUÉ HACE ESTE PAQUETE
- Añade al administrador Decap CMS una sección «Google Analytics».
- Preconfigura el ID de medición G-5PKYXG6CRR en src/data/analytics.json.
- Carga la etiqueta oficial de Google gtag.js en el <head> compartido de las páginas del sitio.
- La medición se activa solamente cuando el ID G-... está presente y tiene un formato válido.

ARCHIVOS INCLUIDOS (solo estos tres archivos)
1. public/admin/config.yml
2. src/layouts/Base.astro
3. src/data/analytics.json

CÓMO APLICARLO
1. Hacé una copia de seguridad del repositorio GitHub antes de reemplazar archivos.
2. En el repositorio monipes/mi-portfolio, rama main, reemplazá los dos archivos existentes:
   - public/admin/config.yml
   - src/layouts/Base.astro
3. Agregá el archivo nuevo:
   - src/data/analytics.json
4. Guardá los cambios en main. Cloudflare Pages debería ejecutar un nuevo despliegue.
5. Cuando termine, abrí https://misssam.online/admin.
6. En el menú del administrador aparecerá «Google Analytics» > «Medición de MISS SAM».
   El campo ya estará rellenado con G-5PKYXG6CRR. No hace falta que pegues otro código.
7. Si en el futuro cambiás de propiedad de Analytics, podrás actualizar ese ID desde el panel y publicar los cambios.
8. Tras el despliegue, abrí Google Analytics > Informes > Tiempo real y visitá tu sitio en otra pestaña para comprobar la recepción de actividad. Google advierte que los datos pueden tardar un poco en aparecer.

IMPORTANTE SOBRE LOS TRES IDENTIFICADORES
- G-5PKYXG6CRR: ID de medición de GA4. ESTE es el identificador instalado.
- 16406229059: ID numérico del flujo web. Es una referencia interna del flujo y no sustituye al ID G- en la etiqueta gtag.js.
- GTM-TJ9835KL: ID de un contenedor de Google Tag Manager. No se instala en esta integración directa de GA4.

El fragmento que se recibió mezclaba la ruta gtm.js con el ID GTM- y comandos gtag(). Google documenta que para instalar directamente GA4 debe utilizarse gtag.js con el ID de medición G-. Por eso este paquete usa G-5PKYXG6CRR mediante gtag.js y no instala el contenedor GTM-TJ9835KL. Si más adelante se desea administrar etiquetas mediante Google Tag Manager, habrá que configurar GA4 dentro de ese contenedor y cambiar a una instalación GTM completa; no deben mezclarse ambos métodos.
